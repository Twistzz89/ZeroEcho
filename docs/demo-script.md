# 演示视频与复现顺序

[播放零点回声模拟器实录：3 分 32 秒](evidence/zero-echo-demo.mp4)。视频连续采集实际模拟器显示内容，按采集时间编码。剪掉了两段操作之间的等待，补充中文字幕，全片无配音。图像区域保留原竖屏比例。成片为 H.264，已完整解码核验。[媒体参数与剪辑区间](evidence/video-verification.json)

|成片位置（约）|操作与观察点|
|---|---|
|00:00—00:34|新游戏，保留信息，信任为 50。在档案中展开实验笔记，进入档案柜。|
|00:34—01:04|错答 1111 扣一次机会。结束应用进程再启动，恢复 15 次机会。正确输入 0417。|
|01:04—01:42|信任不足时协助选项锁定。查网关日志后取得任务配置，独立路线得到局部修复。|
|01:42—02:42|另一局从信任 60 的调查中段继续。用 00:00 与事件先后校正时间线，取得完整真相并查看线索。|
|02:42—03:01|打开结果与决策回顾，保留结局并选择读取手动槽 1。|
|03:01—03:32|确认读档。相同的第 13 步只补查配置，得到局部修复，图鉴同时保留两个结果。|
